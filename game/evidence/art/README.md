## 目视结果与限制

已检查五组绑定的 180 个逐帧组合。身体动作行、主副手装配、原生手掌遮挡、剑挥斩/刀劈/枪刺的对应关系可辨；长柄武器可伸出身体 64×64 画布，未按单格裁切。黄巾剑兵没有修改源清单的兼容列表，游戏适配记录在 `src/data/art-mapping.json`。

关羽、刘备与张飞仍为通用身体，不能把头像差异解释为专属小人。离屏检查不能证明真实浏览器播放节奏、缩放点击、完整游玩或用户审美验收通过；这些结果需在游戏验收记录中独立列出。

## 可重复资源检查

在 `game/` 执行：

```sh
node scripts/check-assets.mjs
```

检查结果保存在 [check-assets.json](check-assets.json)。检查涵盖导入文件 SHA256、PNG 签名与尺寸、实际运行依赖、源资源 ID、九动作与逐帧掌心、UI 面板九宫格。配置 `ART_PACK_ROOT` 可明确指定原始美术库；无源库的新环境仍能检查完整导入包，报告会明确外部源未复核。

PNG 完整解码通过浏览器 `Image.decode()` 执行，独立于此脚本的头信息与结构检查。运行清单沿用源元数据中的可选旧装配字段，但当前绘制器只读取 `file`、`handFile`、`rigFile` 和实际武器依赖；未导入旧通用手型、无用装备身体或立绘武器层。
