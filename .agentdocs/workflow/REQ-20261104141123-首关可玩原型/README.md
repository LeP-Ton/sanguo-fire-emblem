- 用户视觉审美、教学引导体验与多种打法的长期平衡尚未人工验收；现有数值保持原型身份。
- 关羽是通用丹阳身体，黄巾剑兵为游戏侧适配；不是专属人物小人重绘。
- 底部桥无法可靠接入 64 像素网格，仍是不可进入景观。主战场、全部部署点与左侧桥正常连通。
- 首关及刘关张标记 `playable`；简雍已实现剧情入队但战斗能力仍为 `draft`，其余章节及人物为 `planned`。
